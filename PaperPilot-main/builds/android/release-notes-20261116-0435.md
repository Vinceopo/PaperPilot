### What's fixed in this build
- **Manuscript upload soft-lock:** Upload no longer stays stuck on "Preparing preview..." if the WebView/CDN hangs — unlocks after preview ready or a short timeout so you can continue to File Details and Analyse
- **Android S3 upload:** Uses native FileSystem upload / File reads instead of `fetch(file://).blob()`, which often failed on release APKs
- Preview CDN load failures surface to the app so the overlay can clear
- Document picker also accepts `*/*` then validates PDF/DOCX client-side (Android file managers that omit MIME types)
- mobile-main design/UI kept from the last push
