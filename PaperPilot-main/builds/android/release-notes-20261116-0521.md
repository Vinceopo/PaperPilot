### Root cause of "undefined is not a function"
After picking a PDF, the app read the file header with `FileHandle.readBytes()`, which returns a **Promise**. Calling `.subarray()` on that Promise crashed with `undefined is not a function` (shown in red under the dropzone).

### What's fixed
- Use `readBytesSync` for PDF signature / type checks (no Promise leak)
- Manuscripts remain **PDF only** (DOCX rejected)
- Covered by vitest (`uploadLimits.test.js`) — 31 tests passed before this build
- Keeps prior fixes: upload unlock timeout, Android S3 upload path, inline manuscript title list
